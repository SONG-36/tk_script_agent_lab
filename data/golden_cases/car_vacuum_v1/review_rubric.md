# Review Rubric: Car Vacuum Golden Case

## CreativeIdea Review

| Criteria | Pass Standard |
|---|---|
| 商品相关 | 创意围绕车内清洁，不泛化成任意清洁产品 |
| 事实准确 | 不编造吸力、续航、防水、认证或医学清洁能力 |
| 卖点绑定 | 至少使用一个已确认 SellingPoint，并能追溯到 ProductFact |
| 参考借鉴 | 借鉴 Hook、结构或镜头模式，而不是复制参考视频 |
| Hook 强度 | 前 3 秒有明确视觉冲突或痛点 |
| 可拍摄 | 普通手机、车内场景和产品即可拍摄 |
| 来源完整 | SourceUsage 解释来源被用于哪里和为什么 |
| 风险可控 | 避免绝对化、夸大、侵权和不可验证表达 |

## ScriptDraft Review

| Criteria | Pass Standard |
|---|---|
| 绑定创意 | 剧本严格基于选中的 CreativeIdea |
| 剧本完整 | 包含 Hook、分镜、口播、产品展示和 CTA |
| 平台节奏 | 适合 20-35 秒 TikTok 短视频 |
| 产品真实 | 不新增无依据产品功能 |
| 可执行 | 拍摄人员能理解需要拍什么 |
| 来源保留 | 主要主张能反查来源 |
| 人工审核 | 未审核不得导出为 approved |

## Scoring

每项 1-5 分。

建议通过线：

```text
CreativeIdea average >= 4.0
ScriptDraft average >= 4.0
No P0/P1 safety issue
No F01/F02/F03/F14 failure
```

## Failure Codes To Watch

- F01 商品事实幻觉
- F02 卖点无事实支持
- F03 引用不存在
- F04 SourceUsage 不完整
- F07 剧本偏离创意
- F08 参考视频复制风险
- F11 禁用表达
- F14 人工闸门绕过
